# Prestigia Yacht Dubai

Luxury Yacht Charter Booking Website

## Features
- Fully responsive design (desktop, tablet, mobile)
- Booking form with date/time selection
- Payment modal (Card & USDT TRC20)
- Gallery with lightbox
- VIP pickup service section
- Google reviews section
- Legal pages (Privacy, Terms, Refund, Cookie, Disclaimer)

## Quick Start

```bash
npm install
npm start
```

Visit `http://localhost:3000`

## Deploy to GitHub Pages (Static)

For static hosting, convert to static HTML:
1. Replace form submission with direct email/WhatsApp
2. Remove server-dependent features
3. Upload `public/` folder contents

## Deploy to Vercel/Railway/Render

1. Push to GitHub
2. Connect repo to hosting platform
3. Set build command: `npm install`
4. Set start command: `node server.js`

## Tech Stack
- Node.js + Express
- HTML5, CSS3, Vanilla JS
- Google Fonts (Playfair Display, Montserrat)
